### SDK注册管理

### GDUSDKManager
GDUSDKManager是SDK与普宙飞行器一起使用的入口。这个类主要用于注册SDK，连接和访问飞行器。
通过GDUSDKManager 的注册方法registerApp注册成功后，调用startConnectionToProduct开始与飞行器建立连接，
建立连接后，通过GDUSDKManager.getProduct()获取到无人机产品,然后通过无人机产品类获取相应的组件类，如
getCamera()获取到相机组件，在使用相机组件的方法控制相机完成相应动作


- getInstance()
  描述：获取GDUSDKManager实例  
  返回值： GDUSDKManager

- registerApp(Context context, SDKManagerCallback callback)
  描述：注册初始化SDK
  输入参数： Context上下文 SDKManagerCallback注册回调监听
  返回值： void

- getProduct()
  描述：获取当前飞行器实体类  
  返回值： BaseProduct

- interface SDKManagerCallback
  描述：注册状态结果回调
  void onRegister(GDUError error)
  注册结果回调error == GDUError.REGISTRATION_SUCCESS表示注册成功。

  void onProductDisconnect()
  设备连接断开回调

  void onProductConnect(BaseProduct product)
  设备连接回调

  void onProductChanged(BaseProduct product)
  设备变化回调

  void onComponentChange(BaseComponent oldComponent, BaseComponent newComponent)
  组件连接回调

  void onInitProcess(GDUSDKInitEvent initEvent, int totalProcess)
  初始化进度回调

- startConnectionToProduct()
  描述：开始建立SDK和飞行器的连接，这个方法必须要在registerApp成功后调用。
  返回值： void

- stopConnectionToProduct()
  描述：断开SDK和飞行器的连接
  返回值： void

- getSDKVersion ()
  描述：获取SDK的版本号
  返回值： String 当前版本号


### BaseProduct
BaseProduct基础产品抽象类，飞行器将继承这个类，这个类将提供飞行器的连接，SN的获取，健康状态等功能


- getProductSN()
  描述：获取连接的产品SN 如飞行器
  输入参数：
  返回值：String 飞行器SN

- setDiagnosticsInformationCallback(DiagnosticsInformationCallback allback)
  描述： 设置健康管理监听
  输入参数： DiagnosticsInformationCallback 回调接口
  返回值：void

- isConnected()
  描述： 飞行器是否连接判断
  返回值：Bolean 是否连接


### BaseComponent
BaseComponent基础组件抽象类，飞行器的各个组件将继承这个类，提供版本号获取，连接状态反馈等


- getFirmwareVersion()
  描述：getFirmwareVersion(CommonCallbacks.CompletionCallbackWith<String> version)
  输入参数： CompletionCallbackWith 版本号回调监听
  返回值：String 组件版本号

- setComponentListener(BaseComponent.ComponentListener componentListener)
  描述：设置组件连接状态监听
  输入参数： ComponentListener 连接回调接口
  返回值：Void

- isConnected()
  描述：组件是否连接判断
  返回值：Boolean 组件是否连接


### GDUAircraft
GDUAircraft飞行器实体类，继承BaseProduct，包含飞行器基本信息，获取各个组件。实体类通过GDUSDKManager.getProduct()获取。


- getFlightController()
  获取飞控组件

- getBattery ()
  获取电池组件

- getRemoteController ()
  获取遥控器组件

- getGimbal ()
  获取云台组件

- getCamera ()
  获取相机组件

- getAirLink()
  获取图传组件

- getVision()
  获取视觉组件

- getLTE()
  获取LTE组件

- getNoFlyZone()
  获取禁飞区组件
