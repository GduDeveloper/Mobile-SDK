### SDK注册管理

### SDKManager
`SDKManager` 是将 Mobile SDK 与普宙飞行器一起使用的核心入口类（单例模式）。用于注册 SDK、建立/断开与飞行器的通信连接、设置工作场景以及获取飞行器实例。

通过 `SDKManager` 的注册方法 `registerApp` 注册成功后，调用 `startConnectionToProduct` 开始与飞行器建立通信连接。建立连接后，通过 `SDKManager.getInstance().getProduct()` 获取到无人机产品对象（Aircraft），然后通过产品类获取相应的组件类（如 `flightController()` 获取飞控组件，`camera()` 获取相机组件）来控制飞行器。

*包路径：`com.gdu.sdk.manager.SDKManager`*

- **getInstance()**
  描述：获取 `SDKManager` 单例实例
  返回值：`SDKManager`

- **registerApp(Context context, SDKManagerCallback callback)**
  描述：注册初始化 SDK
  输入参数：`Context` 上下文，`SDKManagerCallback` 注册回调监听
  返回值：`void`

- **getProduct()**
  描述：获取当前飞行器实体对象
  返回值：`BaseProduct?` (实际上是 `Aircraft` 实例)

- **startConnectionToProduct()**
  描述：开始建立 SDK 和飞行器的通信连接，需在 `registerApp` 成功后调用
  返回值：`void`

- **setConnectScene(ConnectScene scene)**
  描述：设置连接场景（`ConnectScene.RC`: 普通遥控器模式, `ConnectScene.HANGAR`: 机巢模式, `ConnectScene.CUSTOM_RC`: 自定义遥控器模式）
  返回值：`void`

- **getSDKVersion()**
  描述：获取 SDK 的版本号（当前返回 "V4.0"）
  返回值：`String`

- **getDeviceManager()**
  描述：获取底层设备管理器对象
  返回值：`IDeviceManager`

- **destroy()**
  描述：销毁并释放 SDK 资源
  返回值：`void`

### interface SDKManagerCallback
描述：SDK 全局状态与组件连接监听回调接口。

- **onRegister(Error error)**
  描述：SDK 注册结果回调，成功返回 `Error.REGISTRATION_SUCCESS`。

- **onProductConnect(BaseProduct? product)**
  描述：飞行器连接成功回调。

- **onProductDisconnect()**
  描述：飞行器断开连接回调。

- **onProductChanged(BaseProduct? product)**
  描述：飞行器更换回调。

- **onComponentChange(BaseComponent? oldComponent, BaseComponent? newComponent)**
  描述：飞行器子组件（飞控、云台、相机、电池、图传等）连接状态变更回调。

- **onInitProcess(SDKInitEvent event, int totalProcess)**
  描述：SDK 初始化进度事件回调。

### BaseProduct
`BaseProduct` 基础产品抽象类，`Aircraft`（飞行器实体）继承该类，提供飞行器连接判定、SN 获取、机型查询以及健康管理状态监听等功能。

*包路径：`com.gdu.sdk.base.BaseProduct`*

- **getProductSN(CommonCallbacks.CompletionCallbackWith<String> callback)**
  描述：获取飞行器序列号 SN
  输入参数：`CompletionCallbackWith<String>` 回调接口
  返回值：`void`

- **getModel()**
  描述：获取飞行器具体型号（如 S200, S400, P200 等）
  返回值：`Model` 枚举

- **setDiagnosticsInformationCallback(Diagnostics.DiagnosticsInformationCallback callback)**
  描述：设置健康管理/故障诊断监听回调
  输入参数：`DiagnosticsInformationCallback` 回调接口
  返回值：`void`

- **isConnected()**
  描述：获取飞行器当前是否连接正常
  返回值：`boolean`

---

### BaseComponent
`BaseComponent` 基础组件抽象基类，飞控、电池、遥控器、云台、相机、图传等组件均继承该类。

*包路径：`com.gdu.sdk.base.BaseComponent`*

- **getDeviceId()**
  描述：获取当前模块所属的设备 ID
  返回值：`int`

- **getFirmwareVersion(CommonCallbacks.CompletionCallbackWith<String> version)**
  描述：获取组件固件版本号
  输入参数：`CompletionCallbackWith<String>` 版本号回调监听
  返回值：`void`

- **setComponentListener(ComponentListener componentListener)**
  描述：设置组件连接状态变化监听
  输入参数：`ComponentListener` 连接回调接口
  返回值：`void`

- **isConnected()**
  描述：判断组件当前是否已连接
  返回值：`boolean`

---

### Aircraft
`Aircraft` 飞行器实体类，继承自 `BaseProduct`。通过 `SDKManager.getInstance().getProduct()` 获取。包含飞行器全部硬件及功能子组件。

*包路径：`com.gdu.sdk.products.Aircraft`*

- **flightController**
  描述：获取飞控组件

- **battery**
  描述：获取电池组件

- **remoteController**
  描述：获取遥控器组件

- **gimbal**
  描述：获取云台组件（支持多光/不同型号云台多态解析）

- **camera**
  描述：获取相机组件（支持 8K, 30X, PDL1K 等多态解析）

- **airLink**
  描述：获取图传无线链路组件

- **vision**
  描述：获取 AI 视觉感知与目标跟踪组件

- **radar**
  描述：获取毫米波/超声雷达避障感知组件

- **megaphone**
  描述：获取 PSDK 喊话器控制组件

- **lte**
  描述：获取 4G/5G 备份图传通信组件

- **noFlyZone**
  描述：获取禁飞区管理组件

- **hms**
  描述：获取飞行器健康管理系统组件

- **codecManager**
  描述：获取视频硬件编解码管理组件

- **videoFeeder**
  描述：获取视频码流分发器

- **nestController**
  描述：获取机库控制组件
