# Msdk Demo 智能跟踪功能操作文档

## 功能概述
智能跟踪是 Msdk Demo 中的核心 AI 功能之一，支持多目标识别、目标锁定与自动跟随。本文档基于 Msdk Demo 实际操作流程，详细说明智能跟踪功能的完整操作步骤。

## 操作步骤

### 1. 开启智能跟踪
点击**「智能跟踪」**功能按钮，开启智能跟踪功能。此时按钮为初始未开启状态，点击后进入功能激活状态。

### 2. 多目标识别
开启功能后，界面进入多目标识别状态，实时显示识别到的目标。视频画面中需包含**人、车、船**等可识别目标，系统将自动检测并以标识框标注。

### 3. 锁定目标
点击画面中的目标标识（或手动在画面中画框框住目标），进入目标锁定状态。此时选中的目标将被高亮标记，系统将聚焦该目标。

### 4. 开始跟随
点击**「GO」**按钮，进入目标跟随状态。系统将自动追踪锁定目标的位置变化，保持目标在画面中心。

### 5. 取消目标锁定
点击**「取消」**按钮，退出目标锁定状态，返回多目标识别状态。可重新选择其他目标进行锁定。

### 6. 停止跟随
点击**「Stop」**按钮，退出目标跟随状态，返回多目标识别状态。可重新锁定目标或退出功能。

### 7. 退出智能跟踪
在功能选中状态下，再次点击**「智能跟踪」**按钮，退出此功能。界面恢复为普通显示状态。

## 操作流程总览
1. 点击「智能跟踪」→ 开启功能
2. 识别目标（人/车/船）→ 界面实时标注
3. 点选目标 / 手动画框 → 锁定目标
4. 点击「GO」→ 进入跟随
5. 点击「取消」→ 退出锁定（返回第 2 步）
6. 点击「Stop」→ 停止跟随（返回第 2 步）
7. 点击「智能跟踪」→ 退出功能

## 注意事项
1. 开启智能跟踪前，请确保视频画面中存在可识别目标（人、车、船等），否则多目标识别无结果。
2. 目标锁定后，需点击「GO」才会开始跟随，仅锁定不会自动跟随。
3. 「取消」与「Stop」功能不同：「取消」退出锁定状态，「Stop」退出跟随状态，两者均返回多目标识别界面。
4. 退出智能跟踪功能后，再次点击按钮可重新开启。
