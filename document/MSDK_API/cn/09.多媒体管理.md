### 多媒体管理

### GDUMediaManager
可通过多媒体管理类获取相机中拍摄的图片和视频文件，
通过GDUCamera.getMediaMangager()获取媒体管理类


- enable()
  进入下载模式，此时会关闭图传实时画面传输

- disable()
  退出下载模式，恢复图传实时画面传输

- getMediaFileList()
  获取相机媒体文件列表

- getThumbnail(String path)
  获取缩略图
  path: 媒体文件路径

- getPreview(String path)
  获取预览图

- getRawImage(String path)
  获取原图

- getVideoFile(String path)
  下载视频文件

- playVideo(String path)
  开始回放视频文件

- seekVideo(String path)
  跳转视频文件回放

- pauseVideo(String path)
  暂停视频文件回放

- stopVideo(String path)
  停止视频文件回放

- setVideoPlaybackListener()
  设置视频回放监听
