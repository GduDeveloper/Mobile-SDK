# LTEManager 开发者调用文档

本文基于 `LTEManager.java` 的公开 API 与内部调用链整理，聚焦 LTE/4G 备份链路的开发用法与常见调用顺序。

## 1. 适用场景

`LTEManager` 主要负责：

- 切换图传链路模式（SDR / 4G / AUTO）
- 配置/读取 MQTT 与视频流服务地址
- 建立 MQTT 连接
- 上报 LTE 状态信息

## 2. 公开方法一览

以下为 `LTEManager` 中的 public 方法，按功能分组：

### 2.1 生命周期与连接

- `LTEManager(Context context)`
  - 构造函数，初始化 Handler、Socket 监听、轮询检查链路状态。
- `connectMqttService(CommonCallbacks.CompletionCallback callback)`
  - 建立 MQTT 连接。
- `isConnected()`
  - 返回 MQTT 是否已连接。
- `disconnect()`
  - 断开 MQTT 连接并释放客户端资源。

### 2.2 配置与查询

- `setAirlinkType(AirlinkType airlinkType, CommonCallbacks.CompletionCallback callback)`
  - 设置链路模式，如 SDR / LTE / AUTO。
- `setLTELinkInfoCallback(LTELinkInfo.Callback callback)`
  - 注册 LTE 状态回调。
- `setMqttServiceUrl(String mqttServiceUrl, CommonCallbacks.CompletionCallback callback)`
  - 设置 MQTT 地址。
- `getMqttServiceUrl(CommonCallbacks.CompletionCallbackWith<String> callback)`
  - 查询当前 MQTT 地址。
- `setVideoServiceUrl(String videoServiceUrl, CommonCallbacks.CompletionCallback callback)`
  - 设置视频服务地址。
- `getVideoServiceUrl(CommonCallbacks.CompletionCallbackWith<String> callback)`
  - 查询当前视频服务地址。


## 3. 调用步骤（推荐顺序）

### 第一步：创建实例

```java
LTEManager lteManager = new LTEManager(context);
```

### 第二步：注册状态监听（建议在连接前）

```java
lteManager.setLTELinkInfoCallback(new LTELinkInfo.Callback() {
    @Override
    public void onUpdate(LTELinkInfo state) {
        // 处理网络状态、信号强度、连接状态等
    }
});
```

### 第三步：配置服务地址（可选但常用）

```java
lteManager.setMqttServiceUrl("tcp://xxx.xxxx.com:5672", error -> {
    if (error == null) {
        // 设置成功
    }
});
```

或者读取当前配置：

```java
lteManager.getMqttServiceUrl(new CommonCallbacks.CompletionCallbackWith<String>() {
    @Override
    public void onSuccess(String s) {
        // 获取到 MQTT 地址
    }

    @Override
    public void onFailure(GDUError error) {
        // 失败处理
    }
});
```

视频地址也按同样方式处理：

```java
lteManager.setVideoServiceUrl("rtmp://xxx:1935/live/", error -> {
    // 设置视频流地址
});
```

### 第四步：建立 MQTT 连接

```java
lteManager.connectMqttService(error -> {
    if (error == null) {
        // MQTT 连接成功
    } else {
        // MQTT 连接失败
    }
});
```



### 第五步：切换链路模式（按需）

```java
lteManager.setAirlinkType(AirlinkType.AUTO, error -> {
    if (error == null) {
        // 切换成功
    }
});
```

或者：

```java
lteManager.setAirlinkType(AirlinkType.CELLULAR_MOBILE_LINK, callback);
lteManager.setAirlinkType(AirlinkType.IM_LINK, callback);
```


### 第六步：销毁时断开连接

```java
lteManager.disconnect();
```

在页面或应用退出时建议调用，避免 MQTT 客户端残留、连接异常或资源泄漏。

## 1. 简易流程图

```mermaid

    A[创建 LTEManager(context)] --> B[构造函数初始化 Handler / Socket / 链路检查]

    C --> D{是否配置服务地址}
    D -- Yes --> E[setMqttServiceUrl / getMqttServiceUrl]
    D -- No --> F[直接连接 MQTT]
    E --> F
    F --> G[connectMqttService]
    G --> H{连接成功?}
    

    H[业务调用 setAirlinkType] 

```


## 2. 实际开发建议

1. 建议在 `Activity`/`Fragment` 的 `onCreate` 中创建 `LTEManager`，并在 `onDestroy` 中调用 `disconnect()`。
2. 在建立 MQTT 前，优先设置 `setMqttServiceUrl()`，避免使用空地址导致连接失败。
3. 如果业务层需要展示网络状态、链路切换结果，必须注册 `setLTELinkInfoCallback()`。
4. 若使用链路切换功能，调用 `setAirlinkType()` 时应检查当前连接状态和业务条件，避免切换前的空状态异常。
5. 对于 MQTT 消息、空中心跳和遥杆数据，建议统一在上层做异常处理和重试策略。

## 3. 推荐用法示例

```java
public class DemoActivity extends Activity {
    private LTEManager lteManager;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        lteManager = new LTEManager(getApplicationContext());

        lteManager.setLTELinkInfoCallback(state -> {
            if (state != null) {
                // 更新 UI
            }
        });

        lteManager.setMqttServiceUrl("tcp://XXX:5672", error -> {
            if (error == null) {
                lteManager.connectMqttService(result -> {
                    if (result == null) {
                        // MQTT 连通
                    }
                });
            }
        });
    }

    @Override
    protected void onDestroy() {
        super.onDestroy();
        if (lteManager != null) {
            lteManager.disconnect();
        }
    }
}
```

## 4. 总结

`LTEManager` 是 LTE/4G 备份链路的核心入口，开发者最常使用的调用链为：

```text
new LTEManager(context)
-> setLTELinkInfoCallback()
-> setMqttServiceUrl()（可选）
-> connectMqttService()
-> setAirlinkType()（链路切换）
-> disconnect()（资源释放）
```

只要按照上述顺序调用，通常即可完成 LTE 备份链路的初始化、连接、消息通信和链路切换。
