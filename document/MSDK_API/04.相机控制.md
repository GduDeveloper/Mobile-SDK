### 相机控制


### GDUCamera
GDUCamera更改相机设置和执行相机操作的方法，通过GDUSDKManager.getProduct().getCamera()获取到相机组件。


- startShootPhoto(CommonCallbacks.CompletionCallback callback)
  在相机拍照模式下，相机开始拍照

- stopShootPhoto(CommonCallbacks.CompletionCallback callback)
  停止拍照，连拍时可使用

- startRecordVideo(CommonCallbacks.CompletionCallback callback)
  在录像模式下，相机开始录像

- stopRecordVideo(CommonCallbacks.CompletionCallback callback)
  停止当前录像

- setMode(CameraMode cameraMode, CommonCallbacks.CompletionCallback completionCallback)
  设置拍照或录像模式
  CameraMode:拍照/录像模式
  SHOOT_PHOTO：拍照模式
  RECORD_VIDEO：录像模式

- getMode(CommonCallbacks.CompletionCallbackWith<CameraMode> callback)
  获取当前拍照/录像模式

- setStorageStateCallBack(StorageState.Callback callback)
  设置相机存储状态
  StorageState：相机存储状态

- setSystemStateCallback(SystemState.Callback callback)
  设置相机状态信息监听
  SystemState：相机状态信息

- getFirmwareVersion(CommonCallbacks.CompletionCallbackWith<String> callback)
  获取版本号

- formatSDCard(CommonCallbacks.CompletionCallback callback)
  格式化SD卡

- isOpticalZoomSupported()
  是否支持光学变焦

- getOpticalZoomSpec (CompletionCallbackWith<SettingsDefinitions.OpticalZoomSpec> callback)
  获取光学变焦参数

- setOpticalZoomFocalLength(int focalLength, CommonCallbacks.CompletionCallback callback)
  设置光学变焦焦距

- getOpticalZoomFocalLength(CommonCallbacks.CompletionCallbackWith<Integer> callback)
  获取光学变焦镜头焦距

- startContinuousOpticalZoom (SettingsDefinitions.ZoomDirection direction,
  SettingsDefinitions.ZoomSpeed speed, CommonCallbacks.CompletionCallback callback)
  开始连续光学变倍

- stopContinuousOpticalZoom(CommonCallbacks.CompletionCallback paramCompletionCallback)
  停止连续变倍

- setDisplayMode(SettingsDefinitions.DisplayMode displayMode, CompletionCallback callback)
  设置相机的显示模式
  DisplayMode:
  THERMAL_ONLY：单红外
  VISUAL_ONLY：单可见光  
  MSX：融合  
  WAL：可见光定焦
  ZL：可见光变焦
  PIP：分屏
  OTHER: 未知

- getDisplayMode(CommonCallbacks.CompletionCallbackWith<SettingsDefinitions.DisplayMode> callback)
  获取相机的显示模式

- getMediaManager()
  获取相机媒体管理类


### VideoFeeder
VideoFeeder管理移动端实时流，获取相机流或者FPV流


- getPrimaryVideoFeed()
  获取主要的视频输入源，一般为相机输出


### VideoFeed
VideoFeed视频源。用于接收来自相机源的视频数据。


- addVideoDataListener(VideoFeeder.VideoDataListener dataListener)
  添加视频流数据监听
  VideoDataListener: onReceive(byte[] datas, int len)
  datas: H264/H265数据
  len: H264/H265数据长度


### GDUCodecManager
GDUCodecManager用来解码相机视频流，包含H264/H265数据


- GDUCodecManager(Context context, SurfaceTexture surfaceTexture, int width, int height)
  构造解码管理器
  surfaceTexture:图像渲染的surface texture view
  Width：surface的宽
  Height:surface的高

- sendDataToDecoder(byte[] data, int len)
  发送视频流H264/H265给解码器进行解码

- startStoreMp4ToLocal(String path, String fileName)
  开始存储H264/H265视频流为Mp4文件到指定路径
  path:mp4在手机或者遥控器存储路径
  filename: mp4文件名称

- stopStoreMp4ToLocal(String path, String fileName)
  停止存储，开始存储后必现调用，不然存储mp4有播放问题

- enabledYuvData(Boolean enable)
  开启硬解码yuv数据

- setYuvDataCallback(YuvDataCallback yuvDataCallback)
  设置yuv数据的回调监听，必现调用enableYuvData方法，且enable为true

- getYuvData()
  获取当前图像的yuv数据，必现调用enableYuvData方法，且enable为true

- getRgbaData()
  获取当前图像的RGBA数据，必现调用enableYuvData方法，且enable为true

- startStoreMp4ToLocal(String path, String fileName)
  开始存储H264/5图像数据为MP4文件到指定路径
  path:mp4存储路径
  filename:mp4文件名称

- stopStoreMp4ToLocal()
  停止存储H264/5图像数据为MP4文件

- storageCurrentStreamToPicture(String path, String name, CompletionCallback callback)
  存储当前视频图像以图片形式到本地
  path: 图片路径
  name: 图片名称
